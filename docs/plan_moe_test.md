# Σχέδιο: τεστ εφικτότητας δεύτερου agent (MoE) (γράφτηκε 27/11/2026, ΠΡΙΝ τρέξει)

## Γιατί
Το qwen3:8b λύνει 8/16 εργασίες banking χωρίς επίθεση (στις άγνωστες μόνο την 0): το utility υπό επίθεση δεν μετριέται σε
πολλές εργασίες (floor effect) και όλα τα αποτελέσματα είναι με 1 μοντέλο. Πρόταση επιβλέποντα: μοντέλο Mixture of Experts.
Υποψήφιο: qwen3:30b-a3b (30B συνολικές / ~3B ενεργές παράμετροι, ~18-19 GB σε 4-bit, tools κατά τη σελίδα του Ollama).
Ο guard (κλήσεων + εξόδων) μένει qwen3:8b, παγωμένος. Κώδικας: defenses.build_pipeline(agent_model=, guard_model=),
run_bench.py --agent-model/--guard-model (ελέγχθηκε με ψεύτικο server: agent -> μοντέλο agent, guards -> μοντέλο guard).

## Τι τρέχει (ΜΟΝΟ benign, καμία επίθεση: δεν «καίγεται» καμία εργασία)
16 εργασίες banking x 2 ρυθμίσεις (none, guard2_oguard) x 1 επανάληψη = 32 επεισόδια. Μετά από κάθε ρύθμιση: ollama ps, nvidia-smi.
Το guard2_oguard κόβεται στα 45 λεπτά. Εκτίμηση: ~10 λεπτά λήψη μοντέλων + ~15-20 none + ≤ 45 guard2_oguard ≈ ≤ 1.3 ώρες GPU.

## Ρίσκο μνήμης (αριθμητική, όχι μέτρηση)
2 x T4 = ~30 GB. qwen3:30b-a3b ~18.6 GB βάρη + KV cache (32k context x 2 παράλληλα αιτήματα, εκτίμηση ~6 GB) + qwen3:8b
(~16 GB με 2 παράλληλα, μετρημένο 20/11) = πάνω από 30 GB. Πιθανό: το Ollama εναλλάσσει τα μοντέλα ή βάζει μέρος σε CPU
-> πολύ αργό guard2_oguard. Αυτό ακριβώς μετράει το βήμα 2. Αν συμβεί, επιλογές: OLLAMA_NUM_PARALLEL=1 ή μικρότερο context.

## Κριτήρια (γράφτηκαν πριν): το MoE γίνεται «κύριος» agent για το dev αν
1. tool calling δουλεύει: 0 σφάλματα / Traceback, κάθε επεισόδιο καλεί εργαλεία όταν χρειάζεται·
2. benign utility ≥ 12/16 (qwen3:8b: 8/16)·
3. διάμεση διάρκεια επεισοδίου (none) ≤ 1.5 x του qwen3:8b (~48 s benign, Π9 logs) -> ≤ ~75 s·
4. guard2_oguard τελειώνει τα 16 επεισόδια μέσα στα 45 λεπτά (τα δύο μοντέλα «χωράνε» μαζί).
Αν 1-2 περάσουν αλλά όχι 3-4: το MoE μπαίνει μόνο στην τελική αξιολόγηση (με ρυθμίσεις μνήμης). Αν 1 ή 2 αποτύχουν: δοκιμή gpt-oss:20b.
Με 16 επεισόδια η σύγκριση utility είναι περιγραφική (Fisher 8/16 vs 14/16: p ≈ 0.05· vs 12/16: p ≈ 0.27).
